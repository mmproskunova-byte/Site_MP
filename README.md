
можно не загружать — на работу сайта они не влияют.

## Публикация на GitHub Pages

1. **Создайте репозиторий.** Имя — `Site_MP`, тип — **Public**.

2. **Загрузите файлы.** На странице репозитория: *Add file → Upload files*, перетащите файлы из списка
   выше (папку `images` — целиком). Внизу нажмите *Commit changes*.

3. **Добавьте `.nojekyll`**, если его не видно в списке файлов (в проводнике Windows файлы такого вида
   бывают скрыты): *Add file → Create new file*, имя — `.nojekyll`, оставьте пустым → *Commit changes*.
   Файл необязателен, но с ним GitHub Pages публикует файлы ровно как есть.

4. **Включите Pages.** *Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.*

5. **Проверьте адрес.** Через 1–2 минуты сайт откроется по адресу **https://mmproskunova-byte.github.io/Site_MP/**

6. **Если адрес другой** — замените адрес сайта в трёх файлах (больше нигде не встречается):
   - `index.html` — строки с `rel="canonical"`, `og:image` и `og:url`;
   - `robots.txt` — строка `Sitemap: …`;
   - `sitemap.xml` — строка `<loc>…</loc>`.

Ссылки внутри сайта и пути к картинкам относительные, поэтому менять их при смене адреса не нужно.

## Обновление сайта

Файл заменяется прямо на GitHub (*Add file → Upload files* с тем же именем, или откройте файл →
карандаш → правки → *Commit changes*). Новая версия появляется на сайте через минуту.

## Что заменить при желании

1. **Фото.** Сейчас используется заглушка `images/photo-placeholder.svg`. Замените на реальное фото
   (формат 4:5, светлый фон, лицо крупно) и поправьте имя файла и `alt` в `index.html`.
2. **Скриншот FlowBoard** — `images/FlowBoard.png`. При замене обновите `width`/`height` в теге `<img>`.
3. **Превью для Telegram** — `images/og-image.png` (1200×630). Если картинка изменится, оставьте те же размеры.
4. **Контакты** — `app.js`, строки `TELEGRAM_URL` и `EMAIL` в самом начале файла. Они подставляются
   во все 6 кнопок Telegram и в почтовую ссылку.

## Визуал на странице

- Блок «Из чего состоит карточка, которая продаёт» в первом экране: строка поиска, макет карточки товара (линейная SVG-иконка кроссовка вместо фото), четыре нумерованные метки и плашка «В 2 раза за месяц после запуска» со ссылкой на кейс. Свёрстан на HTML и CSS, без картинок.
- Тонкие линейные иконки у всех четырёх услуг.
- График роста продаж в кейсе «Карточки — магнит для продаж».
- Скриншот доски FlowBoard и скриншоты демо-лендингов (фотограф и йога-студия) в учебных проектах.
- Иконки шагов работы, иконки вопросов, иконка финального блока и подвала.
- Фото-заглушка 4:5 в блоке «Обо мне».
- Иконка сайта: `favicon.svg` для браузеров и `images/apple-touch-icon.png` (180×180) для телефонов.

## Проверено

- Все 10 блоков из ТЗ присутствуют, порядок соответствует разделу 4.
- Адаптивность проверена на ширинах 320–1600 px — горизонтальной прокрутки нет; метки в первом экране
  переходят из строки рядом с карточкой (768 px и шире) в список под ней (узкие экраны).
- Кнопки Telegram (6 шт.) и почтовая ссылка заполняются из `app.js`.
- Контраст текста не ниже AA, у ссылок видимый фокус.
- Учебные проекты подписаны как учебные, вымышленных клиентов и отзывов нет.
- Один `h1`, осмысленные `alt`, Open Graph для превью, `lang="ru"`, учтена настройка «меньше движения».

## Служебные файлы

- `robots.txt` и `sitemap.xml` — для поисковых систем.
- `404.html` — страница «Такой страницы нет» в стиле сайта.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.
- `.gitignore` — исключает рабочие файлы, если будете работать через Git или GitHub Desktop
  (при загрузке через сайт GitHub он не действует — просто не выбирайте лишние файлы).
